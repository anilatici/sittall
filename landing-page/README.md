# SitTall Landing Page

Open `index.html` in a browser — no build step or dev server needed.

## Asset files to add

Drop these into the `assets/` folder:

| File | Description |
|------|-------------|
| `hero-menubar.png` | Screenshot of MacBook menu bar with SitTall icon + macOS notification banner |
| `demo.mp4` | Screen recording walkthrough of the app (~30 seconds) |
| `demo-poster.jpg` | Poster frame for the video player |
| `demo-captions.vtt` | WebVTT captions track for the demo video (can be empty initially) |
| `step-01-calibration.png` | Screenshot of the calibration UI |
| `step-02-menubar.png` | Screenshot of the menu bar icon in context |
| `step-03-notification.png` | Screenshot of the macOS notification |
| `mas-badge.svg` | Official Mac App Store download badge from [Apple Marketing Resources](https://developer.apple.com/app-store/marketing/guidelines/) |
| `favicon.png` | The existing SitTall app icon |
